# 人工复核清单 · 视频播放链路（2026-08-03）

> 用途：CI 自动化（`video-playback.spec.ts`）已覆盖"上传→转码→发布→选课→
> 学习视图 mp4 播放推进 + VideoPlayer HLS（hls.js + 签名双通道）播放推进"。
> 以下场景因浏览器策略 / 真实设备差异无法（或不适合）全自动断言，

## 环境

- 本地开发栈：前端 http://localhost:8088（admin）、后端 http://localhost:8089（api）
- 建议浏览器：Chrome 桌面 / Safari 桌面 / iPhone Safari（H5）
- 准备：任取一门已发布课程，用教师端上传一段真实视频（建议 ≥30s），
  走完"提交审核 → 教务审批 → 发布"；学生端选课。

## 1. 学习视图（默认播放链路 · mp4）

- [ ] `/student/learning?courseId=X`：进入即渲染 `<video>`，**不出现永久骨架屏**（P0-2 回归）
- [ ] 播放/暂停/进度条拖拽/倍速 0.5-2x/全屏均可用
- [ ] 播放中页面标题为课程名；章节列表高亮当前课时
- [ ] 播完自动标记完成，进度刷新后恢复上次位置

## 2. VideoPlayer 沉浸播放页（HLS · hls.js）

- [ ] `/student/courses/X/play/:videoId`：视频真实播放推进，无"视频播放出错"浮层
- [ ] 开发者工具 Network：m3u8 与 .ts 分片请求全部 **200**
  - m3u8 URL 带 `?sign=`（原生降级场景）
  - 分片请求带 `X-Video-Sign` 请求头（hls.js 场景）
- [ ] 无 401/403/404 流请求；F12 Console 无 `12003 视频签名无效` / 网络错误
- [ ] 返回/章节切换/笔记/倍速/全屏正常

## 3. 课程详情页"播放预览"

- [ ] 课程详情 → 播放预览：视频真实播放（hls.js + 签名头），无 403/404
- [ ] 预览关闭（X / 返回）后视频停止且无残留音频

## 4. 弹窗与键盘（交叉人工项）

- [ ] 播放器相关确认弹窗（如重试确认、删除笔记确认）：**取消 / X / ESC** 均可关闭且无副作用
- [ ] Tab 键可聚焦播放器控制项；进度条支持左右方向键快进快退

## 5. 移动端 H5

- [ ] iPhone Safari（原生 HLS）：`<video>` 使用 `?sign=` query 直链播放正常
- [ ] 横竖屏切换后播放不中断；`playsinline` 生效（不弹系统播放器）
- [ ] 触屏手势（点按播放/暂停、拖动进度）可用

## 6. 异常与安全回归

- [ ] 未选课学生访问播放页 → 提示"请先选课"（403 8005），页面不白屏
- [ ] 直接访问带过期/伪造 sign 的流 URL → 403 12003
- [ ] 教师端对非本人课程视频上传/管理 → 403 10003

## 7. 转码任务

- [ ] 上传后状态 UPLOADING → TRANSCODING → COMPLETED；失败可重试
- [ ] 转码中学习视图显示进度而非骨架屏卡死
