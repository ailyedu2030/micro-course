# 全页面功能点验证矩阵（Feature-Point Level）

> 本文件是全页面审查任务的**唯一进度真相**。
> 粒度铁律：**功能点级**（每个按钮/操作/状态/边界独立一行），禁止页面级 ✅。
> ✅ 必须附"交互动作 → 实际结果"证据；仅"打开页面无报错"一律标 ⬜/🟡。
> 完成标准：**全部功能点 ✅** 才算矩阵全绿，才可输出完成报告。
> 维护：每次审查先读本文件，逐项执行更新并提交。
